# Day 003: Deduplicate without losing order

**Track:** Foundations

## Challenge

Remove duplicate values while preserving the first occurrence of each value.

## My solution

Covering empty input, case sensitivity, and set limitation as an edge case.

def remove_duplicates(items):
    result = []
    seen = set()

    for item in items:
        if item not in seen:
            result.append(item)
            seen.add(item)

    return result

games = [
    "Skyrim",
    "Pokemon",
    "Skyrim",
    "Baldur's Gate",
    "Pokemon",
    "Minecraft",
]

print(remove_duplicates(games))
