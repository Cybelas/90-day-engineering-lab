# Day 001: Reverse words safely

**Track:** Foundations  
**Timebox:** 15–25 minutes

## Challenge

Write a function that reverses word order while handling repeated whitespace.

## Definition of done

- [ ] Include a concrete solution, example, command, test, query, or diagram.

## My solution

def reverse_words(sentence):
    words = sentence.split()
    reversed_words = words[::-1]
    result = " ".join(reversed_words)
    return result

print(reverse_words(" MOGO     DOES    NOT    SOCIALIZE   "))
