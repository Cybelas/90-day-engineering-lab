# Day 002: Build a frequency map

**Track:** Foundations  
**Timebox:** 15–25 minutes

## Challenge

Count occurrences in a collection and return entries in a deterministic order.

## Definition of done

## My solution

def count_occurrences(items):
    counts = {}

    for item in items:
        if item in counts:
            counts[item] += 1
        else:
            counts[item] = 1

    result = sorted(counts.items())

    return result

games = [
    "Skyrim",
    "Pokemon",
    "Skyrim",
    "Baldur's Gate",
    "Pokemon",
    "Skyrim",
]

print(count_occurrences(games))


## What I learned

A nice little refresher on loops, they let you inspect each lil thing in a collection, a dictionary will let you remember what you've seen, and return will hand you the final answer back so the rest of the program can use it.
