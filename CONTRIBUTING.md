# Contributing

This repository is deliberately optimized for small, reviewable changes.

1. Pick the first exercise marked `todo`.
2. Timebox the work to 15–25 minutes.
3. Replace both `TODO` prompts with a solution and a short reflection.
4. Run `node scripts/progress.mjs --complete <day>`.
5. Commit the exercise and updated progress together.

Prefer a small working example over a long theoretical answer. If an exercise
reveals a gap, record it honestly and turn it into a follow-up issue.
